# MindEase 🌿

MindEase is a full-stack mental health and wellness application designed to help users track their emotional state, practice mindfulness, and engage with positive reinforcement.

## 🚀 Key Features

*   **User Authentication:** Secure registration and login flows utilizing JSON Web Tokens (JWT) and Spring Security.
*   **Mood Tracking:** Log and monitor emotional states over time to identify patterns.
*   **Digital Journaling:** A private digital diary allowing users to securely record their thoughts and daily experiences.
*   **Guided Breathing Exercises:** Integrated audiovisual relaxation tools featuring breathing animations and calming soundscapes.
*   **Engagement Tools:** Daily wellness tips and interactive riddles to keep users engaged and promote positive habits.

## 🛠️ Technology Stack

**Backend:**
*   Java Spring Boot (MVC architecture)
*   Spring Security & JWT for authentication
*   Maven

**Frontend:**
*   Node.js web environment
*   NPM package management
*   ESLint & Prettier for code formatting
